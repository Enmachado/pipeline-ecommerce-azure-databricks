# Pipeline E-commerce | Azure + Databricks + Power BI

Projeto de Engenharia de Dados que implementa um pipeline completo para análise de
vendas de e-commerce utilizando Azure Data Lake Storage Gen2, Azure Databricks,
Delta Lake e Power BI, seguindo a arquitetura Medallion (Bronze → Silver → Gold).

## 🔗 Dashboard ao vivo
[Acesse o dashboard aqui](https://enmachado.github.io/pipeline-ecommerce-azure-databricks/)

## 📂 Estrutura
- `notebooks/` — notebooks Databricks (Bronze, Silver, Gold)
- `index.html` — dashboard interativo (visualização final)
- `vendas_ecommerce.csv` / `.xlsx` — base de dados

## 🛠️ Tecnologias
Azure Data Lake Storage Gen2 · Azure Databricks · Delta Lake · PySpark · Power BI
